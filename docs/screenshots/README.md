# Application Screenshots

Capture screenshots from the **real deployed Currency Exchange Tracker application** and add them to this directory.

Recommended filenames:

- `01-login.png`
- `02-overview.png`
- `03-convert.png`
- `04-trends-threshold.png`
- `05-portfolio.png`
- `06-history.png`
- `07-alerts.png`
- `08-settings.png`
- `09-mobile-overview.png`

Guidelines:
- Use the production application.
- Prefer screenshots that show meaningful application state rather than empty browser chrome.
- Do not include real passwords, tokens, private email addresses, or other secrets.
- Use consistent browser zoom and sensible viewport sizes.
- Keep screenshots focused on the user workflow being demonstrated.

The root README references this directory so the final portfolio can present the application visually without fabricating evidence.
